# 개발 방향 — GAS 데모

지금 만드는 것은 **Ability System(GAS 재구현) 데모**다. 전체 게임 기획(아이템·전투·씬 등 GAS가 아닌 부분)은 보관해 두었다 → [_parked/project/design.md](../_parked/project/design.md).
구현된 데모는 → [project/demo.md](../project/demo.md).

## 방향

- 완성된 게임이 아니라, GAS 기능이 **한 씬 안에서 서로 맞물려 동작하는 데모**를 만든다.
- 시스템(아키텍처)은 깊게, 콘텐츠는 데모 씬에 필요한 만큼만 만든다.
- 각 기능은 UE를 그대로 옮기지 않고, 실제로 동작하는 최소 버전으로 만든다.
- 범위 밖: 네트워크 복제·예측, AbilityActorInfo.

## 기술 선택

- **UI Toolkit** — 데모 HUD(어트리뷰트 바·쿨다운·상태 아이콘)를 만드는 수단으로 쓴다.
- **연출용 트윈** — GameplayCue(연출 레이어)를 만들 때 붙일 생각이었다. Cue를 아직 만들지 않아 DOTween 패키지는 제거했고, 필요해지면 다시 넣는다.
- **에셋 그래프(노드) 에디터** — 마지막 순위의 선택 사항. GraphView 직렬화 비용이 커서, 한다면 가장 좁은 범위(예: GE 하나 저작)로 먼저 확인한다.
