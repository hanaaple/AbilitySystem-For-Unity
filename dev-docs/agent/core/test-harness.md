# test-harness — 테스트 원칙

**에이전트가 테스트를 돌릴 때 따른다.** 상위: [HARNESS.md](HARNESS.md). 이 프로젝트에서 실제로 돌리는 방법(셀프체크·NUnit·Play·격리·도구 제약)은 [../project/unity-test-harness.md](../project/unity-test-harness.md).

---

1. **눈으로 확인할 변경은 에이전트가 직접 테스트한다.** "확인해 주세요"로 넘기지 않는다.
   - **단, 매 작업마다 돌리지 않는다** — 모아 두고 한꺼번에 한다. 컴파일 확인은 매번 한다.
2. **테스트 중 유저 조작은 결과를 망칠 때만 막는다.** 막아야 하는 조작을 새로 찾으면 다음 테스트부터 미리 막고 프로젝트 쪽 '격리'에 더한다.
3. **테스트가 끝나면 실행 상태를 항상 되돌린다 — 유저가 조종 중이어도.** 테스트가 바꾼 설정·임시 에셋·장치 상태도 원래대로.
