# equipment — 결정 기록

> 트레이드오프가 있었던 설계 결정의 상세(맥락·대안·근거·결과·재평가 트리거). 품질 기준은 일반 [HARNESS.md](../../../HARNESS.md) §8.
> **ID(`D#`)는 feature 내 고유·불변**이며 progress 인덱스·worklog가 이 코드로 이 표를 가리킨다. progress엔 요지 인덱스만 두고, **해당 영역을 건들 때 이 파일을 연다.**

| ID | 날짜 | 결정 | 대안 | 채택 사유 |
|---|---|---|---|---|
| D1 | 2026-07-05 | `item-system` 3분할 시 장비를 별도 feature로 격리, **현재 착수 제외** | item/inventory에 포함 | 장착·스탯 배선은 ASC(GAS)와 얽혀 수명·의존이 별개. 인벤/코어 먼저 서고 나서 배선하는 게 검증 순서상 자연스러움 |
| D2 | 2026-07-05 | `EquipmentComponent`은 **ASC에만 의존, `PlayerCharacter` 종속 금지** | 캐릭터를 직접 참조 | "연결되지만 종속 안 됨" 요구. ASC는 재사용 컴포넌트라 seam으로 적합 (INV-6/7/11) |
