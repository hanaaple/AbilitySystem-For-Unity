## 유저 확정 요구사항 (2026-07-18)

무기 설계가 만족해야 할 것. 유저가 직접 명시한 것만 적는다 — 해법·구조는 아직 미정(유저가 정함).

1. **무기는 캐릭터에 종속되지 않는다.**
2. **무기는 캐릭터의 행동에 영향을 준다.** (단순 Fire/Hold뿐 아니라 여러 가지)
3. **단순히 `Weapon`에 `Fire`를 상속하는 방식으로는 부족하다.** 무기는 검·활·총 등 다양하며, 근접 무기도 그 안에서 다양하다.
4. **캐릭터는 어떤 무기든 장착하면 바로 쓸 수 있다.**
