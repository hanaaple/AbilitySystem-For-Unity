# feature/HARNESS.cases — feature/HARNESS.md 사례 아카이브

> 최종 갱신: 2026-08-23 (KST)

`feature/HARNESS.md`(feature 문서 작성 규약)의 **규칙이 왜 생겼는지**를 보여주는 **실제 발생 사례 모음**이다. 규칙 본문은 "무엇을 하라"만 담고, 그 근거가 된 사례는 여기로 분리했다 — `HARNESS.md` 본문의 `→ 사례 [C-NN]` 포인터가 이 문서의 해당 항목을 가리킨다.

- **성격:** 아카이브(과거 스냅샷). 사례 본문은 발생 당시 기록을 **그대로 보존**한다 — 오기 정정 외에는 고치지 않는다(금지 사항: 과거 기록 삭제/수정).
- **ID:** `C-NN`은 **이 파일 안에서** 유일한 안정 식별자다(문서별 로컬 번호). 한 번 부여하면 재번호하지 않고, 새 사례는 다음 번호를 이어 붙인다.
- **추가 방법:** 세션 회고·하네스 자체 점검에서 재발 방지가 필요하면, ① 규칙은 `feature/HARNESS.md` 본문에 넣고 ② 그 근거 사례는 여기에 새 `C-NN`으로 추가한 뒤 ③ 본문 규칙에 `→ 사례 [C-NN]` 포인터를 건다.
