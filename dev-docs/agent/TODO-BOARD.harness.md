# TODO-BOARD.harness — 작업 보드(TODO-BOARD.md) 규약

> [HARNESS.md](HARNESS.md)에서 분리된 **작업 보드 규약**이다. `TODO-BOARD.md`(와 완료 아카이브 `TODO-DONE.md`)의 구조·유지 규약을 담는다.

---

## 작업 보드 (TODO-BOARD.md)

`feature-list.md`가 **feature 단위**를 추적하는 반면, `TODO-BOARD.md`는 그보다 **잘게 쪼개진 잡다한 작업·개인 TODO·이슈**를 모으는 별개 레이어다. (문서 정비, 인프라, 실험, 리팩터, 아이디어 등 feature로 묶기 애매한 것)

### 구조
- 상태 칸: `## 📋 TODO` → `## 🔧 진행 중`. 끝난 항목은 보드에서 빼 **`TODO-DONE.md` 맨 위로 이동**한다(최신이 위, 복제 금지). 보드의 `## ✅ Done` 칸엔 그 파일 안내만 둔다(유저: "TODO 완료된 것들은 파일 별개로 빼자").
- **단, 이 칸 구성은 에이전트가 지키는 기본 틀일 뿐이다 — 보드는 유저도 직접 쓴다.** 유저가 칸을 쪼개 두었거나(예: `📋 TODO (당장 목표)` / `📋 TODO (우선순위 낮음)`) 형식에서 벗어난 항목이 있으면 **그대로 존중하고, 규약에 맞춘다며 임의로 재편·병합·삭제하지 않는다.** 에이전트는 기존 구조에 얹어서 쓰고, 구조 변경이 필요해 보이면 제안만 한다.
- 항목 형식: `- [ ] **(범주)** 내용 — 비고 _(YYYY-MM-DD 등록)_`. 완료 시 `- [x]` + 완료일. 범주 예: `wiki`·`docs`·`infra`·`bug`·`idea`.
- 항목엔 할 일과 결정에 필요한 것만 적는다. 경위·메타·인용 반복·값 나열은 적지 않는다.
- 각 칸이 비면 `(없음)`으로 명시한다.

### 유지 규약 (반자동 — 훅 아님)
- **세션 시작 시** 이 보드를 한 번 훑는다(`진행 중`에 걸린 게 있는지 확인).
- **포착:** 채팅·작업 중 할 일/이슈/아이디어가 나왔는데 보드에 없으면 → 그 자리에서 `📋 TODO`에 추가한다. (사용자가 명시적으로 지시하지 않아도, 놓치지 않게 잡아 둔다)
- **상태 전이:** 어떤 항목에 착수하면 `🔧 진행 중`으로, 끝나면 `TODO-DONE.md`(완료일 기입)로 옮긴다.
  - **하위 항목을 옮길 때 상위 항목도 확인한다** — 남은 하위가 없으면 상위도 완료로 함께 옮긴다
- feature 단위로 커진 항목은 보드에서 빼고 `feature-list.md`에 등록한다(중복 추적 금지).
- 상단에 `최종 갱신`을 둔다. 형식·갱신 시점·값 → docs-harness.md '날짜 작성 방법'.
